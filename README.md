# CENTRAL DE INVESTIGAÇÃO — 3 CASOS

Site educacional em HTML + CSS + JavaScript, pronto para abrir localmente.

## Estrutura
- CASO 001 — OFFLINE: 24 pistas
- CASO 002 — O ARQUIVO 17: 16 pistas
- CASO 003 — PROTOCOLO ZERO: 9 pistas
- O caso seguinte só desbloqueia depois que a equipe conclui a acusação do anterior.
- Acusação exige responsável, motivo, reconstrução e 4 evidências numeradas.
- Caso 003 encerra com reflexão de Setembro Amarelo.

## Gabarito do professor
- Caso 001: Caio
- Caso 002: Beatriz
- Caso 003: Júlia

## Como usar
1. Extraia o ZIP.
2. Abra `index.html`.
3. Informe o nome da equipe.
4. O progresso de desbloqueio fica salvo enquanto a página estiver no navegador.

## Observação
É um site estático: não existe banco de dados nem servidor. Cada equipe pode usar seu próprio computador/navegador.
